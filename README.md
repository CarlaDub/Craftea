# 🎨 Craftea – Application iOS

## 📱 Présentation

Craftea est une application mobile iOS dédiée aux loisirs créatifs.

Elle a été conçue pour faciliter la découverte d'activités créatives et rendre les loisirs plus accessibles.

Ce projet a été réalisé en équipe dans le cadre de l'Apple Foundation Program de Simplon.

## 🎯 Objectifs

- Découvrir de nouveaux loisirs créatifs.
- Encourager la créativité.
- Faciliter l'accès aux activités créatives.
- Proposer une interface simple et intuitive.
- Prendre en compte l'accessibilité des utilisateurs.

## 🛠️ Technologies utilisées

- **Swift** – Langage de programmation
- **SwiftUI** – Création des interfaces
- **Xcode** – Environnement de développement iOS
- **Git et GitHub** – Gestion du code source
- **Figma** – Conception des maquettes

## ✨ Fonctionnalités

- Découverte des loisirs créatifs
- Consultation des détails des activités
- Navigation entre les différentes pages
- Interfaces de profil utilisateur
- Écrans d'inscription et de connexion

## 📂 Organisation du projet

- `Craftea/` : code source Swift
- `View/` : interfaces de l'application
- `Model/` : modèles de données
- `Assets.xcassets/` : images et ressources
- `Craftea.xcodeproj/` : projet Xcode

## ♿ Accessibilité

Craftea vise à proposer une expérience accessible, avec une attention particulière à la lisibilité, aux couleurs et à la simplicité de navigation.
